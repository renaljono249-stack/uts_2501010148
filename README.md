
# UTS Data Acquisition & Management

## Pengumpulan dan Pengolahan Data Tempat Wisata di Yogyakarta

## 1. Deskripsi Proyek

Proyek ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Data Acquisition & Management.

Proyek ini berfokus pada proses pengumpulan, pembersihan, pengolahan, dan penggabungan data tempat wisata di Yogyakarta dari beberapa sumber data.

## 2. Tujuan Proyek

- Mengumpulkan data tempat wisata di Yogyakarta.
- Memeriksa kualitas dan kelengkapan data.
- Membersihkan data kosong dan data duplikat.
- Mengambil data cuaca berdasarkan lokasi Yogyakarta.
- Mengumpulkan informasi tambahan dari website Visiting Jogja sesuai kebijakan akses website.
- Menggabungkan data dari beberapa sumber menjadi satu dataset.

## 3. Sumber Data

Data yang digunakan dalam proyek ini berasal dari beberapa sumber:

1. **Kaggle** – Dataset tempat wisata, rating, dan pengguna.
2. **Open-Meteo** – Data cuaca berdasarkan lokasi Yogyakarta.
3. **Visiting Jogja** – Informasi tambahan mengenai tempat wisata di Yogyakarta.

## 4. Tools dan Teknologi

Tools dan teknologi yang digunakan:

- Python
- Google Colab
- Pandas
- Requests
- BeautifulSoup
- GitHub

## 5. Struktur Dataset

Dataset utama terdiri dari tiga file CSV:

| Nama File | Keterangan |
|---|---|
| `tour.csv` | Berisi informasi tempat wisata |
| `tour_rating.csv` | Berisi data rating tempat wisata |
| `user.csv` | Berisi informasi pengguna |

### Informasi Dataset

- `tour.csv`: 126 baris dan 11 kolom.
- `tour_rating.csv`: 2.870 baris dan 3 kolom.
- `user.csv`: 300 baris dan 3 kolom.
